# Omni Tuya Local v1.11.1

- Actualiza nombres, claves locales y metadatos al sincronizar dispositivos ya registrados.
- Reconcilia el identificador LAN de Tuya tras volver a vincular el mismo dispositivo y conserva la identidad estable de Home Assistant cuando coincide la MAC.
- Actualiza los títulos de configuración y recarga las entidades después de cambios desde Smart Life/Tuya Cloud.
- Incluye la recuperación de comandos LAN, el manejo de rechazos y las regresiones de compatibilidad con Home Assistant Core 2026.10 incluidas en la rama integrada.

La sincronización Cloud se ejecuta bajo solicitud explícita. Esta versión no sustituye la prueba física de restablecimiento y reemparejamiento del dispositivo.
